## 🎓 Impeccable 学到的经验

### Product UI 的核心原则

1. **语义化优先** - 数据关系用 `<dl>`，交互用 `<button>`，不要什么都用 `<div>`
2. **可访问性不是可选** - WCAG AA 是底线，不是目标
3. **状态必须完整** - 每个交互组件需要：default, hover, focus, active, disabled, loading, error
4. **克制是美德** - 产品 UI 应该消失在任务中，不是炫技
5. **一致性胜过惊喜** - 同样的视觉词汇贯穿始终
6. **固定 rem，不要流式** - 产品 UI 在固定 DPI 查看，不需要 clamp()
7. **字重上限 700** - 800 太重，产品 UI 不需要喊叫
