# Dashboard 与账户体验改造设计

> 日期：2026-08-17  
> 已确认方向：方案 A“紧凑运营台”  
> 适用范围：前后台 Layui 与 CrmUI/Naive 双 UI 家族；不引入前后端分离框架。

## 一、目标

本轮不是重做营销页，而是把 CRM 高频运营流程改成清爽、紧凑、可扫描的工作台：主题和语言状态明确；Dashboard 使用真实指标和可切换图表；账户综合、资料、支付、代理链路和实时返佣减少重复入口与阻塞交互；桌面、iPad 和手机均能完成查看、搜索、上传和详情操作。

## 二、视觉系统

### 2.1 视觉方向

- 以浅色工作台为默认，深色为可选主题；所有页面继续使用现有 `crm_themes` 语义 token，不创建页面级第二套颜色事实源。
- 主操作使用清晰蓝色，正向金额使用绿色，风险/拒绝使用红色，待处理使用琥珀色。不得用单一蓝紫、深蓝灰或棕橙覆盖全页。
- 页面背景、顶栏、侧栏、表格和弹层保持明确层级；不使用渐变、装饰光球、玻璃拟态或大面积阴影。
- 卡片圆角不超过 8px；Dashboard 指标允许使用卡片，页面大区块保持无外层套卡。
- 字号不随 viewport 缩放；紧凑面板标题保持 16–20px，正文和表格保持 13–14px，字距为 0。

### 2.2 密度与响应式

- Layui Dashboard 的 `.layui-card-body` 统一收敛到 12–16px 内边距；图表最小高度固定，切换状态不改变布局高度。
- 表格容器铺满可用宽度，左右仅保留 4–8px 安全间距，不使用居中窄容器制造两侧黑边。
- 桌面使用 12 列栅格；iPad 为 6 列；手机为单列。图表、表格工具栏、详情弹层在 `1440×900 / 1280×720 / 768×1024 / 390×844` 下无重叠和横向页面滚动。
- 触控操作目标不小于 44×44px；键盘焦点可见；所有动画控制在 150–250ms，并遵守 `prefers-reduced-motion`。

## 三、全局壳层与主题

### 3.1 语言和主题入口

- 顶栏语言使用 `Languages` 图标，主题使用 `Palette` 图标，按钮本体不显示“语言/皮肤”文字；hover/focus tooltip 显示名称。
- 点击或键盘打开下拉。当前语言、当前主题必须同时具有 check 图标、强调色背景和 `aria-current="true"`，不能只依赖颜色。
- 下拉面板背景、边框、文字、hover 和选中态全部由当前主题 token 驱动；选择后所有 Layui、CrmUI/Naive 页面和 iframe 同步更新。
- WebSocket 测试面板不再拥有独立颜色状态，只消费全局主题源；其他页面与它保持一致。

### 3.2 多语言

- Blade 使用 Laravel 语言包，JavaScript 使用共享 `CrmLang/CRM.t`；不在业务脚本写英文兜底替代缺失 key。
- 静态门禁扫描 `front/common/menu/auth/response/user/register/profile/admin` 命名空间，`zh-CN` 与 `en` 必须同时定义已使用 key；兼容目录 `zh_CN` 同步关键字段。
- 图表标题、legend、tooltip、空状态、时间范围、指标名称和导出列全部使用语言 key。

## 四、Dashboard

### 4.1 信息架构

`.dashboard-hero-main` 第一屏分为三层：

1. 当前账户摘要：账户 ID、角色、认证状态、可用余额和风险状态。
2. 未实名认证引导：仅当真实认证状态不是已通过时显示，主按钮跳转资料页身份认证面板；已认证用户不渲染该 CTA。
3. 运营指标：入金、出金、返佣、订单、代理、客户、间接客户，金额与数量分开显示。

首屏下方显示：资金趋势、订单画像、客户层级画像、风险/认证待办、最近业务记录。Dashboard 不复刻旧项目图表布局。

### 4.2 图表交互

- 每个核心图表支持 `7/15/30 天`分段控件；支持折线、柱状和累计视图时使用图标分段控件，不使用文字按钮堆叠。
- 柱状图、legend、tooltip、轴标签和空状态必须多语言；数据来自 Dashboard API，不在前端生成业务 mock。
- “更多图表”优先增加业务可解释的图：入金/出金净额、订单开平仓、返佣趋势、代理/客户/间接客户金额与数量画像。
- 图表请求失败显示可重试错误态；空结果显示零状态，不伪造趋势。

## 五、账户与个人资料

### 5.1 账户综合合并

- 菜单“账户综合”和“账户余额”合并为一个“账户综合”；旧余额 URL 保留兼容跳转，但不重复显示菜单。
- 页面顶部为资金总览，下面用 tabs 展示余额构成、入金、出金、返佣、订单和客户画像；所有统计读取 `AccountController` 的统一真实数据 DTO。
- 图表支持多语言和 7/15/30 天、折线/柱状/累计视图；统计汇总独立成左对齐 `.table-summary`，不嵌在表格 header 或居中卡片。

### 5.2 资料和验证

- 每个保存按钮只校验所属表单面板；错误信息显示在具体字段下并聚焦第一个错误字段，不再只显示笼统顶部提示。
- 用户注册手机号输入宽度至少 20ch，`maxlength` 允许国际号码并大于 11 位；后端继续执行实际格式与唯一性校验。
- 用户资料必须只读取当前登录用户；姓名、手机号、邮箱、认证、银行卡和头像字段与后端 DTO 一致，不使用旧字段猜测。

### 5.3 上传组件

- Layui 使用当前项目已安装版本的 `upload.render` 标准流程，具备选择、预览、替换、删除、进度、成功和失败状态。
- 身份证固定正面/反面两个上传位；银行卡按业务字段支持正面/反面，后端字段不足时先扩展契约和迁移测试，不能把两张图拼进一个字符串。
- 所有上传入口复用一个轻量初始化模块和统一错误映射，不引入新上传依赖。

## 六、支付、表格与详情

- 支付通道使用 tabs 展示；每个 tab 呈现通道状态、币种、限额、汇率和操作，移动端可横向滚动 tab，但页面本体不横向滚动。
- 所有列表都提供与后端真实 filter 一致的搜索条件；无后端 filter 的控件不得先展示。
- 表格行使用稳定的 odd/even 背景和独立 hover 色；hover 不改变行高。详情操作为真实 button/link，事件委托不能被遮罩或行点击吞掉。
- 所有订单详情在当前 UI 家族弹框显示。桌面最大宽度 960px，iPad 宽度 `calc(100vw - 48px)`，手机全屏或 `calc(100vw - 16px)`；弹框内部 facts 分组，不使用卡片套卡片。
- 测试模拟数据只能通过 `testing + visual_audit=1` fixture 注入；生产空结果不生成 mock。账户流水每个 tab 的视觉验收数据由 testing fixture 提供，并与真实 API 字段一致。

## 七、代理链路与用户详情

- 默认不显示“当前链路 1001 / Demo Root Agent”。只有点击表格用户 ID 后才显示链路。
- 链路只显示用户 ID，截止到当前点击节点；继续点击下一层时追加到第二层，返回上层时截断，不预先展开整棵树。
- 点击用户名打开用户详情弹框，展示入金、出金、返佣金额、返佣比例、开仓/平仓订单数及近 7/15/30 天盈亏图。
- 代理管理移除登录历史展示；登录审计保留在专门安全/在线模块，不与代理业务详情混合。

## 八、实时返佣

- 首次进入只请求分页基础行和汇总，不为每一行预计算详情；返佣明细仅在用户展开某行时按需请求并缓存当前页结果。
- 搜索、防抖、取消过期请求、服务端分页和最大页大小必须明确；不得在浏览器一次渲染全量代理树订单。
- 统计区增加独立折叠层。默认只显示汇总数字；点击 chevron 图标展开图表，再次点击收起。使用 Lucide/Layui 图标，不使用文本 `》` 字符模拟图标。
- 进入页面、切 tab、展开统计和打开详情均有 loading/error/empty 状态；任何错误不能锁死页面主线程。

## 九、数据与安全边界

- 业务页面只读新库 API；旧库永久只读且不从浏览器访问。正式 `co_crmv5` 禁写，PHPUnit 仅写 `co_crmv5_test`。
- `DatabaseSeeder` 默认不得调用 `FrontDemoDataSeeder`。Demo 数据必须要求 `APP_ENV=local/testing` 且显式开关，生产默认失败关闭。
- MT4 永久禁用；图表和详情不能因为 MT4 不可用而返回伪成功或演示金额。
- 任何统计、详情、导出和下钻继续应用当前用户/管理员数据范围；范围外记录返回空或 404，不能靠前端隐藏。

## 十、实施拆分

1. 全局壳层、主题选中态、多语言门禁、表格基础样式。
2. Layui/CrmUI Dashboard 重排、实名认证 CTA、多语言图表和响应式。
3. 账户综合合并、资料字段验证、注册手机号和上传组件。
4. 支付 tabs、统计区、流水 tabs 测试 fixture、响应式详情弹框。
5. 代理链路、用户财务详情图、实时返佣按需加载与折叠统计。

每个子域独立写 TDD 计划并验收，不把五个子域塞进一次高风险大改。

## 十一、验收标准

- 目标 PHPUnit、语言 key、Blade 编译、JavaScript 语法和业务数据源门禁全绿。
- 代表页面在四个视口通过 Playwright：无横向页面溢出、无重叠、弹框可滚动、触控目标和焦点可用。
- 主题下拉可见当前项并随主题变色；语言切换后页面、图表和弹层同步。
- Dashboard 未认证 CTA、账户合并、上传正反面、支付 tabs、代理逐层链路和实时返佣懒加载均由运行时测试证明。
- 不把未执行的浏览器验证、正式迁移或正式库数据修复记为完成。
