# Claude 技能安装说明

## ✅ 已完成：Karpathy Guidelines

**Karpathy Guidelines** 已成功安装到你的 Claude 系统中。

这个技能包含 Andrej Karpathy 的四大核心原则：
1. 只实现被要求的功能
2. 进行精准的外科手术式修改
3. 提前说明假设
4. 定义可验证的成功标准

你现在可以在任何对话中使用 `/karpathy-guidelines` 来激活这个技能。

---

## ⚠️ Superpowers 安装方式

Superpowers 已经存在于你的系统中（位于 `.codex` 目录），但需要通过正确的方式激活。

### 方法 1：通过官方市场安装（推荐）

在 Claude Code 中执行：

```bash
/plugin install superpowers@claude-plugins-official
```

### 方法 2：通过 Superpowers 市场安装

```bash
# 先注册市场
/plugin marketplace add obra/superpowers-marketplace

# 然后安装
/plugin install superpowers@superpowers-marketplace
```

### Superpowers 包含的技能

安装完成后，你将获得以下技能：

**测试类：**
- `test-driven-development` - RED-GREEN-REFACTOR 循环
- `verification-before-completion` - 确保修复真正生效

**调试类：**
- `systematic-debugging` - 4 阶段根因分析流程

**协作类：**
- `brainstorming` - 苏格拉底式设计细化
- `writing-plans` - 详细实施计划
- `executing-plans` - 批量执行检查点
- `dispatching-parallel-agents` - 并发子代理工作流
- `requesting-code-review` - 预审核检查清单
- `receiving-code-review` - 响应反馈
- `using-git-worktrees` - 并行开发分支
- `finishing-a-development-branch` - 合并/PR 决策工作流
- `subagent-driven-development` - 快速迭代与两阶段审查

**元技能：**
- `writing-skills` - 创建新技能
- `using-superpowers` - 技能系统介绍

## 核心哲学对比

### Karpathy Guidelines（纪律与约束）
- 专注于"不做什么"
- 防止过度工程和功能蔓延
- 强调验证循环
- 适用于所有编码任务

### Superpowers（工作流与方法论）
- 完整的开发方法论
- 测试驱动开发
- 系统化调试
- 子代理驱动的开发流程

### 如何结合使用

这两个技能体系是互补的：

- **Karpathy Guidelines** 提供编码纪律，告诉 AI 如何像高级工程师一样思考
- **Superpowers** 提供完整的工作流程，告诉 AI 如何系统化地完成开发任务

建议：
1. 在项目的 `CLAUDE.md` 中引用 Karpathy Guidelines 作为基本行为准则
2. 在具体开发任务中使用 Superpowers 的工作流技能
