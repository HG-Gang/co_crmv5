# 新旧项目业务逻辑对比分析

## 一、CustomerController（旧） vs UserController（新）对比

### 旧项目CustomerController核心功能

#### 1. custListSearch / custListSearchV2（客户列表查询）
**功能：** 复杂的客户列表查询，包含大量统计数据

**特点：**
- ✅ 关联MT4_USERS表获取MT4账号信息（余额、净值、保证金水平）
- ✅ 复杂的交易统计（手续费、盈亏、交易量、利息）
- ✅ 按交易品种分类统计（贵金属、外汇、原油、指数、货币、股票）
- ✅ 入金出金统计（余额入金、余额出金、净入金）
- ✅ 分页统计（当前页汇总 + 全部数据汇总）
- ✅ 数据权限过滤（根据登录管理员权限过滤数据）

**涉及的数据表：**
```sql
- user（用户基础信息表）
- MT4_USERS（MT4账号信息表）
- MT4_TRADES（MT4交易记录表）
- symbol_prices（交易品种价格表）
```

**核心SQL逻辑：**
```sql
-- 1. 客户列表基础查询
SELECT 
    user.user_id, user.user_name, user.parent_id,
    user.trans_mode, user.mt4_code, user.user_money, user.cust_eqy, user.mt4_grp,
    user.user_status, user.voided, user.IDcard_status, user.bank_status, user.rec_crt_date,
    MT4_USERS.LOGIN as mt4_login, 
    MT4_USERS.NAME as mt4_name, 
    MT4_USERS.BALANCE as mt4_balance,
    MT4_USERS.EQUITY as mt4_equity, 
    MT4_USERS.MARGIN_LEVEL as mt4MarginLevel
FROM user
JOIN MT4_USERS ON MT4_USERS.LOGIN = user.user_id
WHERE user.voided IN ('1', '2')
  AND user.user_status IN ('0', '1', '2', '4')
  AND MT4_USERS.REGDATE BETWEEN ? AND ?

-- 2. 按客户统计交易数据
SELECT
    # 余额入金
    SUM(CASE WHEN MT4_TRADES.PROFIT > 0 AND MT4_TRADES.CMD IN (6) 
        AND MT4_TRADES.COMMENT REGEXP 'Deposit|入金' 
        THEN MT4_TRADES.PROFIT ELSE 0 END) as total_yuerj,
    
    # 余额出金
    SUM(CASE WHEN MT4_TRADES.PROFIT < 0 AND MT4_TRADES.CMD IN (6) 
        AND MT4_TRADES.COMMENT REGEXP 'Withdrawal|出金' 
        THEN MT4_TRADES.PROFIT ELSE 0 END) as total_yuecj,
    
    # 手续费
    ABS(SUM(CASE WHEN MT4_TRADES.CMD IN (0,1,2,3,4,5) 
        AND MT4_TRADES.CLOSE_TIME > '1970-01-02 00:00:00' 
        AND MT4_TRADES.MARGIN_RATE <> 0 
        THEN MT4_TRADES.COMMISSION ELSE 0 END)) as total_comm,
    
    # 盈亏
    SUM(CASE WHEN MT4_TRADES.CMD IN (0,1,2,3,4,5) 
        AND MT4_TRADES.CLOSE_TIME > '1970-01-02 00:00:00' 
        AND MT4_TRADES.MARGIN_RATE <> 0 
        THEN MT4_TRADES.PROFIT ELSE 0 END) as total_profit,
    
    # 交易量（手数）
    SUM(CASE WHEN MT4_TRADES.CMD IN (0,1,2,3,4,5) 
        AND MT4_TRADES.CLOSE_TIME > '1970-01-02 00:00:00' 
        AND MT4_TRADES.MARGIN_RATE <> 0 
        THEN MT4_TRADES.VOLUME ELSE 0 END) as total_volume,
    
    # 利息
    ABS(SUM(CASE WHEN MT4_TRADES.SWAPS < 0 
        AND MT4_TRADES.CMD IN (0,1,2,3,4,5) 
        AND MT4_TRADES.CLOSE_TIME > '1970-01-02 00:00:00' 
        AND MT4_TRADES.MARGIN_RATE <> 0 
        THEN MT4_TRADES.SWAPS ELSE 0 END)) as total_swaps,
    
    # 贵金属交易量
    SUM(CASE WHEN MT4_TRADES.SYMBOL IN (
            SELECT sym_symbol FROM symbol_prices 
            WHERE sym_grp_id = 1 AND voided = 1
        ) AND MT4_TRADES.CMD IN (0,1,2,3,4,5) 
        AND MT4_TRADES.CLOSE_TIME > '1970-01-02 00:00:00' 
        AND MT4_TRADES.MARGIN_RATE <> 0 
        THEN MT4_TRADES.VOLUME ELSE 0 END) as total_noble_metal,
    
    # 外汇交易量
    SUM(CASE WHEN MT4_TRADES.SYMBOL IN (
            SELECT sym_symbol FROM symbol_prices 
            WHERE sym_grp_id = 2 AND voided = 1
        ) AND MT4_TRADES.CMD IN (0,1,2,3,4,5) 
        AND MT4_TRADES.CLOSE_TIME > '1970-01-02 00:00:00' 
        AND MT4_TRADES.MARGIN_RATE <> 0 
        THEN MT4_TRADES.VOLUME ELSE 0 END) as total_for_exca,
    
    # 原油交易量
    SUM(CASE WHEN MT4_TRADES.SYMBOL IN (
            SELECT sym_symbol FROM symbol_prices 
            WHERE sym_grp_id = 3 AND voided = 1
        ) AND MT4_TRADES.CMD IN (0,1,2,3,4,5) 
        AND MT4_TRADES.CLOSE_TIME > '1970-01-02 00:00:00' 
        AND MT4_TRADES.MARGIN_RATE <> 0 
        THEN MT4_TRADES.VOLUME ELSE 0 END) as total_crud_oil,
    
    # 指数交易量
    SUM(CASE WHEN MT4_TRADES.SYMBOL IN (
            SELECT sym_symbol FROM symbol_prices 
            WHERE sym_grp_id = 4 AND voided = 1
        ) AND MT4_TRADES.CMD IN (0,1,2,3,4,5) 
        AND MT4_TRADES.CLOSE_TIME > '1970-01-02 00:00:00' 
        AND MT4_TRADES.MARGIN_RATE <> 0 
        THEN MT4_TRADES.VOLUME ELSE 0 END) as total_index,
    
    # 货币交易量
    SUM(CASE WHEN MT4_TRADES.SYMBOL IN (
            SELECT sym_symbol FROM symbol_prices 
            WHERE sym_grp_id = 5 AND voided = 1
        ) AND MT4_TRADES.CMD IN (0,1,2,3,4,5) 
        AND MT4_TRADES.CLOSE_TIME > '1970-01-02 00:00:00' 
        AND MT4_TRADES.MARGIN_RATE <> 0 
        THEN MT4_TRADES.VOLUME ELSE 0 END) as total_currency,
    
    # 股票交易量
    SUM(CASE WHEN MT4_TRADES.SYMBOL IN (
            SELECT sym_symbol FROM symbol_prices 
            WHERE sym_grp_id = 6 AND voided = 1
        ) AND MT4_TRADES.CMD IN (0,1,2,3,4,5) 
        AND MT4_TRADES.CLOSE_TIME > '1970-01-02 00:00:00' 
        AND MT4_TRADES.MARGIN_RATE <> 0 
        THEN MT4_TRADES.VOLUME ELSE 0 END) as total_stock
FROM MT4_TRADES
WHERE MT4_TRADES.LOGIN = ?
```

**数据处理逻辑：**
1. 查询用户列表（分页）
2. 循环查询每个用户的交易统计数据
3. 查询全部符合条件的用户汇总数据
4. 合并数据，返回包含footer（汇总行）的响应

### 新项目UserController现状

#### 当前功能
- ✅ index() - 基础用户列表查询（仅基础字段，无统计）
- ✅ show() - 用户详情查询
- ✅ update() - 用户资料更新
- ✅ updateStatus() - 用户状态切换

#### 缺失功能
- ❌ 复杂的交易统计查询
- ❌ MT4账号信息关联
- ❌ 按品种分类的交易量统计
- ❌ 入金出金统计
- ❌ 分页汇总 + 全部汇总
- ❌ 数据权限过滤

## 二、新项目数据表结构对比

### 新项目表结构（co_crmv5）

```sql
-- 用户相关表
user_logins         -> 登录账号表
user_infos          -> 用户详细信息表
user_auths          -> 用户认证信息表
user_trades         -> 用户交易记录表（替代MT4_TRADES）
user_login_logs     -> 用户登录日志

-- 代理相关表
agent_descendants   -> 代理层级关系表
agent_levels        -> 代理等级配置表

-- 交易相关表
deposit_records     -> 入金记录表
withdraw_records    -> 出金记录表
commission_records  -> 佣金记录表

-- 品种相关表
symbol_prices       -> 交易品种价格表
group_configs       -> 组配置表
```

### 旧项目表结构（new_co_gmtk_crmV3）

```sql
-- 用户相关表
user                -> 用户基础表
MT4_USERS           -> MT4账号信息表
MT4_TRADES          -> MT4交易记录表

-- 品种相关表
symbol_prices       -> 交易品种价格表
user_group          -> 用户组配置表
```
