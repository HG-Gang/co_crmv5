## 📝 关键代码实现说明

### 1. UserStatisticsService核心逻辑

**统计维度：**
```php
// 交易统计
- total_comm：总手续费
- total_profit：总盈亏
- total_volume：总交易量（手数）
- total_swaps：总利息

// 入金出金统计
- total_yuerj：余额入金
- total_yuecj：余额出金
- total_net_worth：净入金（入金-出金）

// 品种分类统计
- total_noble_metal：贵金属交易量
- total_for_exca：外汇交易量
- total_crud_oil：原油交易量
- total_index：指数交易量
- total_currency：货币交易量
- total_stock：股票交易量
```

**关键SQL逻辑：**
```sql
-- 余额入金：CMD=6，PROFIT>0，备注包含"Deposit|入金"
SUM(CASE WHEN profit > 0 AND cmd = 6 AND comment REGEXP 'Deposit|入金'
    THEN profit ELSE 0 END) as total_yuerj

-- 交易盈亏：CMD 0-5，已关闭，保证金率不为0
SUM(CASE WHEN cmd IN (0,1,2,3,4,5) 
    AND close_time > '1970-01-02 00:00:00' 
    AND margin_rate <> 0 
    THEN profit ELSE 0 END) as total_profit

-- 品种分类：根据symbol_prices.group_id匹配
SUM(CASE WHEN symbol IN (贵金属品种列表)
    AND cmd IN (0,1,2,3,4,5) 
    AND close_time > '1970-01-02 00:00:00'
    THEN volume ELSE 0 END) as total_noble_metal
```

### 2. UserController.listWithStats流程

**执行步骤：**
```
1. 获取分页参数和筛选条件
2. 构建基础查询（user_infos + user_logins）
3. 应用筛选条件（user_id、user_name、user_status、日期范围）
4. 应用数据权限过滤（根据当前管理员角色）
5. 执行分页查询，获取当前页用户列表
6. 调用UserStatisticsService批量查询用户统计数据
7. 合并用户基础信息和统计数据
8. 查询全部符合条件用户的汇总统计
9. 构建汇总行数据（totalRow）
10. 返回JSON响应（data + count + totalRow）
```

### 3. 数据权限过滤实现

**HasDataScope Trait使用：**
```php
// 在Model中使用
class UserInfo extends Model
{
    use HasDataScope;
}

// 在Controller中应用
$users = UserInfo::query()
    ->withDataScope('user', 'admin') // 自动过滤数据
    ->paginate(15);
```

**权限类型：**
- 1=全部数据（超级管理员）
- 2=本级及下级（普通管理员）
- 3=仅本级（只看直属下级）
- 4=仅本人（只看自己创建的）
- 5=自定义规则（JSON配置）

## ⚠️ 重要注意事项

### 1. 数据表差异
- 旧项目：`user` + `MT4_USERS` + `MT4_TRADES`
- 新项目：`user_infos` + `user_logins` + `user_trades`
- **注意字段映射关系，避免数据丢失**

### 2. 数据格式转换
- MT4的VOLUME字段需要 **除以100** 才是实际手数
- 日期字段统一使用 **10位UNIX时间戳**
- 金额字段保留 **2位小数**

### 3. 性能优化
- 避免N+1查询问题（使用批量查询）
- 复杂统计考虑使用缓存（Redis）
- 大数据量查询必须分页
- 添加必要的数据库索引
