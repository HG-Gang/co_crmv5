## 🎓 核心经验总结

### Impeccable 教给我们的产品 UI 原则

1. **语义化是底线**
   - 数据关系用 `<dl>/<dt>/<dd>`
   - 交互用 `<button>` 不是 `<div>`
   - ARIA 标签该用就用

2. **设计 token 不是可选**
   - 硬编码颜色是技术债
   - Token 命名要语义化
   - 为主题切换打基础

3. **产品 UI 的克制美学**
   - 字重上限 700，不喊叫
   - 圆角上限 10px，不过度
   - 阴影 blur 上限 12px，要微妙
   - 配色策略 Restrained，少即是多

4. **状态必须完整**
   - 每个交互：default, hover, focus, active, disabled, loading, error
   - 每个列表：正常、加载中、空状态、错误
   - 骨架屏 > 空白屏 > 旋转图标

5. **可访问性是标配**
   - WCAG AA 是底线不是目标
   - 对比度计算不能凭感觉
   - 键盘导航必须能用
   - 触控目标要够大
