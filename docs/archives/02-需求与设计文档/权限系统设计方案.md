# CRM 系统 RBAC 权限方案设计

## 一、方案概述

本方案基于 **RBAC (Role-Based Access Control)** 模型，实现了一套完整的权限控制系统，支持：

✅ 菜单权限控制（Menu Permission）  
✅ 按钮权限控制（Button Permission）  
✅ 接口权限控制（API Permission）  
✅ 数据权限控制（Data Scope Permission）  
✅ 多角色支持（管理员、代理、普通用户）  
✅ 前后端分离架构  

---

## 二、数据表结构说明

### 2.1 核心权限表

#### `permissions` - 权限字典表
存储所有权限节点（菜单、按钮、接口）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint | 主键 |
| name | varchar(100) | 权限名称（中文） |
| slug | varchar(150) | 权限标识（唯一，如 admin_user_create） |
| guard_type | varchar(20) | 守卫类型：admin=后台, front=前台 |
| parent_id | int | 父权限ID，用于构建树形结构 |
| type | tinyint | 类型：1=目录, 2=菜单, 3=按钮/接口 |
| icon | varchar(100) | 图标类名 |
| route | varchar(200) | 前端路由路径 |
| api_route | varchar(200) | 后端API路由名称 |
| sort | int | 排序权重 |
| status | tinyint | 状态：0=禁用, 1=启用 |

#### `roles` - 角色表
存储角色基础信息

| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint | 主键 |
| name | varchar(100) | 角色名称 |
| guard_type | varchar(20) | 守卫类型：admin/front |
| description | text | 角色描述 |
| status | tinyint | 状态：0=禁用, 1=启用 |

#### `role_permissions` - 角色权限关联表
角色与权限的多对多关系

| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint | 主键 |
| role_id | bigint | 角色ID |
| permission_id | bigint | 权限ID |
| created_at | int | 创建时间 |

#### `admins` - 管理员表
后台管理员账号

| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint | 主键 |
| username | varchar(100) | 用户名 |
| password | varchar(100) | 密码（加密） |
| role_id | varchar(60) | 角色ID（支持多角色，逗号分隔） |
| status | tinyint | 状态：0=禁用, 1=启用 |

#### `user_logins` - 前台用户登录表
前台用户（代理、客户）账号

| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint | 主键 |
| user_id | int | 业务用户ID |
| email | varchar(255) | 邮箱 |
| password | varchar(255) | 密码 |
| account_type | tinyint | 账户类型：1=代理, 2=客户 |

#### `user_infos` - 用户详细信息表
存储用户业务数据

| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint | 主键 |
| user_id | bigint | 用户ID |
| parent_id | int | 上级ID（代理树结构） |
| account_type | tinyint | 账户类型：1=代理, 2=客户 |
| group_id | int | 所属组ID |
| level_id | int | 级别ID |

## 三、权限控制层级

### 3.1 四层权限体系

```
┌─────────────────────────────────────────┐
│  第一层：菜单权限（Menu Permission）    │
│  控制左侧导航菜单的显示与隐藏           │
└─────────────────────────────────────────┘
              ↓
┌─────────────────────────────────────────┐
│  第二层：按钮权限（Button Permission）  │
│  控制页面内操作按钮的显示与隐藏         │
└─────────────────────────────────────────┘
              ↓
┌─────────────────────────────────────────┐
│  第三层：接口权限（API Permission）     │
│  后端接口层验证，防止绕过前端直接调用   │
└─────────────────────────────────────────┘
              ↓
┌─────────────────────────────────────────┐
│  第四层：数据权限（Data Scope）         │
│  控制用户只能查看/操作特定范围的数据    │
└─────────────────────────────────────────┘
```

### 3.2 权限判断流程

```
用户请求
    ↓
【1. 身份认证】JWT Token 验证
    ↓
【2. 获取用户角色】从数据库读取 role_id
    ↓
【3. 获取角色权限】从 role_permissions 读取权限列表
    ↓
【4. 接口权限验证】检查当前路由是否在权限列表中
    ↓
【5. 数据权限过滤】根据用户类型过滤数据范围
    ↓
返回数据
```

## 四、数据权限方案（核心）

### 4.1 三种用户角色的数据权限

#### 角色1：超级管理员（Super Admin）
- **数据范围**：全部数据
- **识别方式**：`admins.id = 1` 或 `roles.name = 'super_admin'`
- **SQL过滤**：无过滤条件

#### 角色2：普通管理员（Admin）
- **数据范围**：根据角色权限配置
- **识别方式**：`admins.role_id` 对应的权限配置
- **SQL过滤**：可能需要按部门、区域等过滤

#### 角色3：代理（Agent）
- **数据范围**：只能看到自己及下级的数据
- **识别方式**：`user_infos.account_type = 1`
- **SQL过滤**：
  ```sql
  WHERE user_infos.parent_id = {当前代理ID}
  OR user_infos.user_id = {当前代理ID}
  ```

#### 角色4：普通用户（Customer）
- **数据范围**：只能看到自己的数据
- **识别方式**：`user_infos.account_type = 2`
- **SQL过滤**：
  ```sql
  WHERE user_infos.user_id = {当前用户ID}
  ```

### 4.2 数据权限实现策略

#### 策略1：查询作用域（Query Scope）
在 Model 中定义全局查询作用域，自动过滤数据

```php
// 示例：UserInfo Model
protected static function booted()
{
    // 自动应用数据权限过滤
    static::addGlobalScope('dataScope', function (Builder $builder) {
        $user = auth()->user();
        
        if (!$user) return;
        
        // 超级管理员：不过滤
        if ($user->isSuperAdmin()) {
            return;
        }
        
        // 代理：只看自己和下级
        if ($user->isAgent()) {
            $builder->where(function ($query) use ($user) {
                $query->where('parent_id', $user->id)
                      ->orWhere('user_id', $user->id);
            });
        }
        
        // 普通用户：只看自己
        if ($user->isCustomer()) {
            $builder->where('user_id', $user->id);
        }
    });
}
```
