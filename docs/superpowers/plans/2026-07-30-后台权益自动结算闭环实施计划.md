# 后台权益自动结算闭环实施计划

> **执行要求：** 按测试驱动开发逐项完成；每项先运行失败测试，再写最小实现并复验。

**目标：** 使用真实 MT4 登录映射、可注入网关、原子认领、对账恢复和审计日志完成后台权益自动入出金闭环。

**架构：** 控制器只负责 HTTP 校验与响应，`RightsSettlementService` 负责数据范围后的单条结算状态机；复用现有 `DepositSettlementGateway` 与 `WithdrawalFundingGateway`，不新增协议转发层。数据库迁移把权益主表和明细表升级为可事务、可关联的数据结构。

**技术栈：** Laravel、Query Builder/Eloquent、MySQL InnoDB、PHPUnit、Layui、Lucide。
