## 📝 使用说明

### 当前状态
✅ **所有用户现在访问的是 V2 版本页面**

访问以下路由会看到新版页面：
- `/front/login` → 登录 v2
- `/front/register` → 注册 v2
- `/front/dashboard` → 控制台 v2
- `/front/profile` → 个人资料 v2
- `/front/deposit` → 入金 v2

### 如需回滚到原版

编辑对应 Controller，将 `_v2` 移除：

```php
// 例如：AuthController.php
return view('front_layui::auth.login');  // 去掉 _v2 后缀
```

原始文件完全未被修改，回滚无任何风险。
