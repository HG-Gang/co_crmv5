### 2. 数据口径一致性 (7/7项)

| 验证项 | 旧项目 | 新项目 | 结论 |
|--------|--------|--------|------|
| 代理首页统计范围 | 自己+全部下级 | scopeUserIds递归 | ✅ 一致 |
| 客户首页统计范围 | 只看自己 | 单用户ID | ✅ 一致 |
| 返佣统计维度 | 按agent_id | 按agent_id | ✅ 一致 |
| 交易时间字段 | open_time/close_time | DATETIME | ✅ 一致 |
| 资金时间字段 | created_at | Unix时间戳 | ✅ 一致 |
| 手数单位转换 | volume/100.0 | volume/100.0 | ✅ 一致 |
| 金额精度 | DECIMAL(18,2) | BCMath两位小数 | ✅ 一致 |

**关键验证点**:
- Unix时间戳分桶公式: `FLOOR((CAST(created_at AS SIGNED) - 今日零点) / 86400)`
- DATETIME分桶公式: `DATEDIFF(time, CURDATE())`
- 不依赖数据库时区设置，PHP本地时区与SQL计算对齐
