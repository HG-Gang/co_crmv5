## 一、数据库全中文注释（需求 1）

### 现状与目标

- 原状：76 张表**全部无表注释**；1073 个字段中 785 个为"中文 | English"双语注释、69 个纯英文、176 个缺失、43 个纯中文。
- 目标：**所有表与字段的备注必须全中文**，且与代码逻辑强相关。

### 交付物

| 交付物 | 路径 | 说明 |
|---|---|---|
| 注释映射 | `database/sql/column-comments-map.php` | 76 张表注释 + 176 个缺失字段注释（中文，语义与代码强相关） |
| Laravel 命令 | `app/Console/Commands/AnnotateDatabaseColumns.php` | `php artisan db:annotate-columns` |
| 可执行 SQL | `database/sql/column_comments.sql` | 1149 条 ALTER 语句（1073 字段 + 76 表），可独立执行 |

### 命令用法

```bash
php artisan db:annotate-columns                       # 增量执行（幂等）
php artisan db:annotate-columns --full                # 全量执行
php artisan db:annotate-columns --dry-run             # 预览变更
php artisan db:annotate-columns --export=path.sql --full  # 导出完整可执行 SQL
```

### 处理规则（命令内实现）

1. **双语注释**：取 `中文 | English` 的中文部分（去外层方括号）→ 纯中文；
2. **纯英文注释**：按翻译映射转中文（69 处，含 `ID`→`主键标识`、`IP`→`操作者 IP 地址`、枚举说明等）；
3. **缺失注释**：按映射文件补充（176 处，覆盖佣金转账 Saga、三类 Outbox、资金硬化字段、框架表等）；
4. **中文规范化**：`管理员ID`/`主键 ID` 等统一为"标识"，保留 `JWT ID`/`MT4` 等组合技术术语；
5. **表注释**：76 张表全部补充中文表作用说明；
6. **幂等**：已达标字段自动跳过，重复执行零变更。

### 最终状态（已验证）

- 表注释：76/76 全中文（0 缺失、0 非中文）。
- 字段注释：1073/1073 全中文（0 双语、0 纯英文、0 缺失）。
- 剩余含 ASCII 的注释仅 4 处 `SSO: 当前JWT ID`（组合术语，保留）。
- 防回归测试：`tests/Feature/DatabaseChineseCommentsClosureModuleTest.php`（3 tests）。
