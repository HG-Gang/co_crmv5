## 三、真实 HTTP 冒烟与缺陷修复

### 1. 冒烟范围

对 8 个关键入口 + 全部 GET 页面路由（约 340 条）发起真实 HTTP 请求：

- 关键入口：`/user/login`(200)、`/agents/login`(200)、`/index/admin/login`(200)、`/front-crmui/dashboard`(200)、`/admin-crmui/dashboard`(200)、`/user/register`(修复后 200)、`/whstest`(423 预期 fail-closed)
- 全量 GET 页面：130 个 200 / 108 个 3xx（登录跳转，预期）/ 13 个 423（fail-closed，预期）/ `sanctum/csrf-cookie` 204（正确语义）

### 2. 真实缺陷：`/user/register` 500（已修复）

- 现象：`resources/front/layui/auth/register_v2.blade.php` 渲染抛 `ParseError: syntax error, unexpected identifier "en"`。
- 根因：该模板 3 行中文字符串（L24/L26/L32）为 GBK→UTF-8 双重转码损坏产物（mojibake），且行尾闭合单引号 `'` 丢失，导致 PHP 解析器把后续 `en` 当作标识符。
- 修复：按行号重写 3 行为正确 UTF-8 中文文案并补齐闭合引号：
  - L24 `'按安全访问要求填写资料，创建前台账号。'`
  - L26 `'字段按业务关系分组，减少长表单的压迫感。'`
  - L32 `'完善身份、联系方式与验证信息。'`
- 防回归：`PortalBrandPageClosureModuleTest::test_front_register_v2_view_renders_without_syntax_error` 固化该契约。

## 四、UI 合规修复

### 1. Lucide 图标映射补齐（lucide-bridge.js）

- 现象：数据库 `permissions.icon` 中 4 个图标名不在桥接器 `layuiMap` 中，旧 UI 菜单将退回 layui 字体渲染。
- 修复（`public/js/shared/lucide-bridge.js`）：
  - `layui-icon-vercode` → `key-round`（数据范围/验证码类菜单）
  - `layui-icon-tabs` → `panel-top`（组别配置类菜单）
  - `layui-icon-form` → `file-text`（凭证审核类菜单）
  - `layui-icon-delete` → `trash-2`（注销申请类菜单）
- 全部映射名已验证存在于本地 lucide.min.js v1.26.0 vendor。

### 2. crmui 侧边栏导航图标注入

- 现象：crmui 新 UI 三套侧边栏（后台/前台/大代理）导航为纯文字，无图标，信息层级弱。
- 修复：
  - `CrmUi/Admin/PageController::navGroups()`、`CrmUi/Front/PageController::navGroups()`、`CrmUi/Front/BigAgentPageController::navGroups()` 每个菜单项注入 `icon` 字段（Lucide 名）。
  - 三个布局模板（admin/front crmui layouts + big-agent layout）渲染 `<i data-lucide="{{ $item['icon'] }}">`。
  - `crmui/admin.css`、`crmui/front.css` 增加导航图标尺寸/间距/激活态样式。

### 3. 品牌门户页替换默认脚手架

- 现象：`resources/views/welcome.blade.php` 为 Laravel 8 默认脚手架页（Laravel logo、外部链接），与品牌设计不符。
- 修复：重做为 CO CRM 品牌门户页——设计 token（oklch 色板）、渐变光晕背景、玻璃拟态入口卡片（前台/代理商/后台）、Lucide 图标、主题切换按钮、`prefers-reduced-motion` 降级。
- 补充修复：全量回归发现该页内联 `<script>` 违反 `FrontUiRegressionTest::test_blade_templates_do_not_contain_inline_executable_javascript`（Blade 必须通过 src 加载 JS）。已将主题切换逻辑移入 `public/js/apps/front/welcome-portal.js` 并通过 `<script src>` 引用，回归转绿。

### 4. 死资源清理（已备份）

- 删除无任何引用的静态资源（备份于 `storage/app/backups/dead-vendor-assets-20260801/`）：
  - `public/vendor/adminlte`、`bootstrap`、`fontawesome`、`layui`、`jquery`
  - `public/js/vendor/axios`、`ionicons`、`naive-ui`、`tailwind`、`vue`
