# CoCRM v5 页面效果图包

图片严格分为四个独立界面族目录：`front/layui/`、`front/crmui/`、`admin/layui/`、`admin/crmui/`。大代理端归入 `front/crmui/big-agent/`，并保留其独立入口标识。

每张图片左上角均标记了四位数字序号，例如 `#0023`。请在反馈中直接使用该数字；`PAGE_EFFECT_INDEX.csv` 可用于反查界面端、UI 家族、页面 ID、预览路由和文件名。

页面内还会显示界面端、模块、页面、正式路由及对应 Blade/Controller 视图说明。
