## 一、项目总览

### 1.1 项目背景

本次迁移将旧版 V3 CRM 系统（基于 CodeIgniter 框架，PHP 5.x）完全迁移至新版 co_crmv5 系统（基于 Laravel 10 框架，PHP 8.x），实现了架构升级、代码量精简和安全性增强。

### 1.2 旧项目（V3） vs 新项目（co_crmv5）对比

| 维度 | 旧项目 V3 | 新项目 co_crmv5 |
|------|-----------|-----------------|
| 框架 | CodeIgniter 3.x | Laravel 10 |
| PHP 版本 | 5.6 / 7.0 | 8.1+ |
| 数据库 | 单一 crm_db | co_crmv5（独立数据库） |
| 路由风格 | 隐式 / 传统 URI 分段 | Laravel 命名路由 + RESTful |
| 认证方式 | Session-based | JWT（JSON Web Token） |
| 单点登录 | 无 | Redis 缓存 SSO（SingleSignOn 中间件） |
| 权限模型 | 硬编码/简单判断 | RBAC（roles + role_permissions + permissions） |
| 数据权限 | 无 | AdminDataScopeService + role_data_scopes |
| API 结构 | 按页面分文件 | 按模块分 Controller |
| 前端 UI | Naive UI（旧 JS 模板） | Layui（新版 Blade） + CrmUI（兼容旧 Naive） |
| 中间件模型 | 单一 LoginMiddleware | 链式中间件：JWT - SSO - CheckPermission |
| 测试覆盖 | 无 | 562 个 PHPUnit 测试文件 |

## 二、系统架构

### 2.1 四个 UI 家族

| UI 家族 | 目录 | 技术栈 | 认证方式 | 用途 |
|---------|------|--------|----------|------|
| front_layui | resources/front/layui/ | Blade + Layui.js | JWT (api/front) | 新版前台用户界面 |
| front_crmui | CrmUi\Front\ | CrmUI/Naive UI（兼容旧版） | Legacy Session | 旧版前台界面兼容 |
| admin_layui | resources/admin/layui/ | Blade + Layui.js | JWT (api/admin) | 新版后台管理界面 |
| admin_crmui | CrmUi\Admin\ | CrmUI/Naive UI（兼容旧版） | Legacy Session | 旧版后台界面兼容 |

### 2.2 双 API 层架构

```
请求入口
  +-- /api/front/*  ---> App\Http\Controllers\Front（前台用户 API）
  +-- /api/admin/*  ---> App\Http\Controllers\Admin（后台管理 API）
```

**路由配置：** RouteServiceProvider 分别加载 routes/front.php（前缀 /api/front）和 routes/admin.php（前缀 /api/admin），web.php 加载 Blade 页面和兼容路由。

### 2.3 中间件链路

```
请求进入
  |
  v
[ api 中间件组 ]  SetLocale + throttle:api + SubstituteBindings
  |
  v
[ 1. jwt.auth    ]  JWT鉴权（JwtAuthMiddleware）
  解析 Bearer token -> 验证有效性 -> 设置Auth guard -> 写入jwt_payload/jwt_guard/jwt_token
  失败 -> TOKEN_MISSING / AUTH_FAILED
  |
  v
[ 2. sso         ]  单点登录（SingleSignOn）
  从jwt_payload读取jti/sub/guard -> Cache::get("sso:{guard}:{sub}")
  比对缓存jti与token jti -> 不一致 -> SSO_CONFLICT（被踢下线）
  |
  v
[ 3. check.permission ]  接口权限（CheckPermission）
  获取命名路由名称 -> 白名单检查（菜单/资料/登出/刷新token）
  -> 超级管理员检查（admin.id=1 或 role.name=super_admin）
  -> permissions表校验：guard_type + api_route + status=1
  -> role_permissions角色关联校验
  失败 -> PERMISSION_DENIED
  |
  v
[ 4. Controller  ]  业务逻辑 + AdminDataScopeService 数据范围过滤
```

**中间件注册（Kernel.php）：**

```
jwt.auth         -> JwtAuthMiddleware
sso              -> SingleSignOn
check.permission -> CheckPermission
```

**前台路由保护：** `[jwt.auth:user, sso:user]`  
**后台路由保护：** `[jwt.auth:admin, sso:admin, check.permission:admin]`

**提交入金完整执行链路：**
```
POST /api/front/deposits/submissions
  -> jwt.auth:user -> sso:user
  -> DepositController@submitDeposit
    -> 查询 payment_channels WHERE id=? AND status=1
    -> PaymentGatewayRegistry 路由到具体 Gateway
    -> PaymentOrderService@create
      -> 校验金额范围(deposit_min_amount / deposit_max_amount)
      -> 校验入金开关(deposit_enabled)
      -> DB::transaction
        -> deposit_records INSERT(status=0 待支付)
        -> payment_settlement_outbox INSERT(异步结算事件)
    -> 返回 PaymentOrderResult(含 payment_url)
  -> JSON: {code:0, data:{deposit_id, payment_url, local_order_no}}
```

```
  -> jwt.auth:user -> sso:user

    -> 查询余额(user_infos.balance + mt4_users.equity)
    -> WithdrawalOrderService@create

      -> 校验实名状态(user_auths.status)

      -> 校验金额范围 + 风控(当日次数 x 时间窗口)
      -> 校验余额充足性
      -> DB::transaction
        -> withdraw_records INSERT(status=0 待审核)
        -> withdraw_settlement_outbox INSERT
  -> JSON: {code:0, data:{withdraw_id}}
```

## 附录 B：安全防护检查点

| 检查点 | 实现机制 | 说明 |
|--------|---------|------|
| Token 有效性 | JwtAuthMiddleware | 必须提供 Bearer token，解析 sub/guard/jti 载荷 |
| 会话唯一性 | SingleSignOn 中间件 | Redis Cache `sso:{guard}:{id}` 存储当前有效 jti |
| 被踢下线 | SSO jti 校验 | 缓存 jti 与 token jti 不一致 -> SSO_CONFLICT 错误 |
| 接口权限 | CheckPermission 中间件 | permissions.guard_type + api_route + status=1 + role_permissions |
| 超级管理员 | isSuperAdmin | admin_logins.id=1 或 role.name=super_admin 跳过权限检查 |
| 白名单路由 | isPermissionWhiteRoute | 菜单/个人资料/登出/刷新/改密/头像不需要独立权限 |
| 数据范围 | AdminDataScopeService | role_data_scopes 按角色 + admin_agent_bindings 按管理员 |
| 密码存储 | Bcrypt | Laravel Hash::make / Hash::check |
| CSRF 保护 | VerifyCsrfToken | Web 路由组默认启用 |
| API 限流 | throttle:api | 60 请求/分钟（按用户 ID 或 IP 区分） |
| CORS | HandleCors | 跨域请求头控制 |
